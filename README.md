# Golden era

Gold tubes — canvas infini. Application web statique (React embarqué, page autonome).

## Développement

C'est une page HTML autonome. Ouvre simplement `index.html` dans un navigateur, ou sers le dossier :

```bash
npx serve .
```

## Déploiement

Déployée sur Vercel comme site statique (aucun build requis).
